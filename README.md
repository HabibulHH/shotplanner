# ShotKit

An Android-first, offline-first shot list and on-set companion for filmmakers.

## v1 feature set

- Offline Drift/SQLite persistence for projects, scenes, shots, and settings
- Wedding, interview, music-video, short-film, and blank project templates
- Persistent scene/shot reorder, completion, duplication, archive, and CRUD
- Camera/gallery reference frames with local JPEG compression
- Dark-optimized On-set mode with optional screen wake lock
- Detailed and compact offline PDFs with image fallbacks, verification, preview,
  printing, sharing, and the free watermark
- One-time `pro_unlock` Play Billing entitlement with purchase restoration
- Free creation limits enforced at the database-facing store boundary

Run with `flutter run` or build with `flutter build apk`.
