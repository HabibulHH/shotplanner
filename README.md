# ShotKit

An Android-first, offline-first shot list and on-set companion for filmmakers.

## Features (1.1)

- Offline Drift/SQLite storage for projects, scenes, shots and settings
- Wedding, interview, music-video, short-film and blank project templates
- Guided shot builder (size, angle, movement, lens, camera) with animated
  framing previews, plus a framing glyph for every shot without a photo
- Quick add, swipe to duplicate or delete, explicit reorder mode
- On-set mode with Done / Skip, folded done list, next-scene handoff and a
  persisted daylight palette; optional screen wake lock
- Camera/gallery reference frames with local JPEG compression
- Detailed and compact offline PDFs with image fallbacks, verification,
  preview, printing and sharing
- In-app review prompt after a wrapped scene or shared PDF (from the third
  app open, at most every 90 days)
- Completely free: no accounts, ads, analytics or in-app purchases

Fonts: Archivo and JetBrains Mono, bundled under the SIL Open Font License
(`assets/fonts/`).

Run with `flutter run` or build with `flutter build apk`. Store screenshots
are generated by `test/store_screenshots_test.dart`. Plans for upcoming
releases live in `docs/roadmap/PHASE_2_PLAN.md`.
