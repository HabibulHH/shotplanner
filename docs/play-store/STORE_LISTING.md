### Full description

ShotKit is an offline-first shot planner and on-set companion built for filmmakers, videographers, directors, cinematographers, and production teams.

Turn an idea into an organized production slate. Build projects from practical templates, break them into scenes, and create detailed shots with visual guidance for framing, camera angle, movement, lens, camera, timing, priority, notes, and reference images.

VISUAL SHOT PLANNING

Choose from an extensive filmmaking library of shot sizes, compositions, camera angles, and movements. Sticky animated previews show how each selection changes the frame, so planning stays fast and understandable.

BUILT FOR THE SET

Use On-set mode to move through the shot list, mark coverage complete, protect must-have shots, and keep the screen awake while filming.

OFFLINE BY DESIGN

Projects, scenes, shots, notes, and selected reference images remain on your device. No account is required. Your production plan stays available even when the location has no signal.

PRODUCTION FEATURES

• Project templates for weddings, interviews, music videos, short films, and blank productions
• Scene and shot creation, editing, duplication, reordering, archiving, and restoration
• Guided visual shot builder with animated framing and movement previews
• Reference-image support using the Android system picker
• Must-have coverage and completion tracking
• On-set presentation mode
• Detailed and compact PDF shot-list export and sharing
• Local-first SQLite storage

ShotKit is completely free: unlimited projects, unlimited scenes, all templates, and watermark-free PDF exports. No account, no subscription, no in-app purchases.
