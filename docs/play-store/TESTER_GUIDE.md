# ShotKit closed-test guide

## Tester setup

1. Opt in using the Play testing link with the invited Google account.
2. Install only from Google Play so billing and Play signing are exercised.
3. Keep the account opted in continuously for the required testing period.
4. Send feedback through the Play private-feedback field and [SUPPORT EMAIL OR FORM].

## Required test passes

- Create a project from every template.
- Create, edit, duplicate, reorder, complete, archive, and restore content.
- Walk through every guided shot-builder step.
- Scroll long shot-size, angle, and movement libraries while confirming the preview remains sticky.
- Add and remove a reference image; deny/cancel the picker once.
- Enter On-set mode, navigate shots, and confirm keep-awake behavior.
- Export detailed and compact PDFs, including a long project and missing/corrupt reference-image fallback.
- Rotate the device, change font size, enable dark mode, and test Android Back navigation.
- Go offline, relaunch, edit data, and export a PDF.
- Test ShotKit Pro purchase with a license tester: success, cancel, pending if available, restore, reinstall, and second-device restore.
- Report device model, Android version, steps, expected behavior, actual behavior, and screenshot/video for every bug.

## Production-access evidence to retain

- Tester invitation and opt-in records
- Feedback summaries and issues fixed
- Dates covering the full continuous test window
- Device/Android-version coverage
- Final regression results and Play pre-launch report
